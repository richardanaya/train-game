# Taggart Dispatch

Open index.html in a browser. Each morning, give each of the two locomotives one job — haul iron (2 loads to the mill), haul copper (1 load), haul one rail from the mill onto the John Galt Line, or stand idle — then run the day. If the mill holds at least 2 iron and 1 copper at day’s end, it rolls one rail, which stays there until a train lays it; lay 6 segments within 14 days. index.html, styles.css, and game.js stay at the repository root, which is what GitHub Pages serves at https://richardanaya.github.io/train-game/.
